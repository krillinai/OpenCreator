## What's New

- Improved Creator video translation and media workflows with clearer stage progress, more reliable previews, smoother rendering, and better subtitle delivery steps.
- Improved bilingual subtitle translation quality with checkpoint-aware recovery, bounded length repair, terminology and naturalization safeguards, and preservation of valid translations when a later repair cannot finish.
- Fixed subtitle handling for short source fragments, simplified Chinese output, and CJK text so subtitle lines are less likely to be split unnecessarily.
- Added Creator task telemetry and clearer failure diagnostics to make task progress and outcomes easier to inspect.
- Added support for the newer Doubao Voice console API key format, while preserving the legacy App ID and Access Token flow where required.
- Improved first-run setup with English as the default interface language, language selection during Agent setup, streamlined Creator startup, and refreshed shared preset assets.
- Updated the default LLM model to gpt-5.6-terra, improved managed yt-dlp runtime selection, and removed the retired spaCy runtime from Desktop packaging.
- Added OpenCreator application icons to the Desktop and Web experiences and updated the Web favicon.
- Updated dependencies to address security advisories.
