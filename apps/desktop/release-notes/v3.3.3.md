## What's New

- Replaced the retired direct Google Veo preview with Gemini Omni 1.2 Flash for video generation using your own Google API key. Existing keys and completed videos are retained, and Veo remains selectable through the signed-in OpenCreator service where available.
- Kept the creation composer available across generation history categories and aligned it with the dashboard. Fixed a Desktop connection leak that could stall history requests after switching views.
- Made image, cover, video, and translation failures easier to understand, with specific guidance and retry controls kept next to the affected work.
- Improved video translation retry behavior by reusing completed dubbing segments and checking existing transcription requests before submitting again.
- Added a proxy connectivity check in Network settings and improved error reporting for platform connections and video downloads.
- Reduced interruptions from brief Runtime reconnects and retained completed Agent setup when the Runtime directory changes but the configured provider is still valid.
