# 企业知识库静态页面设计

## 目标

在左侧边栏“插件”下增加“知识库”入口，提供企业知识资产的静态工作台示例。页面只使用 `apps/web` 共享实现，不接入 Daemon、API、存储或平台 Bridge。

## 信息架构

- 顶部：标题、静态示例标识、企业知识库说明和本地搜索。
- 概览：知识条目、知识空间、已同步来源、待更新条目四项指标。
- 筛选：全部、制度规范、产品资料、客户案例、技术文档。
- 内容区：左侧高密度文档列表，右侧选中文档详情；移动端改为上下排列。
- 字段：稳定 ID、标题、摘要、分类、空间、来源类型、所有者、可见范围、更新时间、同步状态、标签和内容节选。

## 交互与状态

- 搜索匹配标题、摘要、空间和标签。
- 分类筛选与搜索组合生效。
- 点击文档行更新右侧详情；过滤后若当前选择不可见，自动选择首条结果。
- 空结果明确展示，不提供上传、编辑、删除或同步等伪操作。
- 页面和详情明确标注为静态示例数据。

## 一致性与验证

- Browser Bridge 和 Desktop Bridge 使用相同路由、DOM、数据与样式。
- 覆盖路由解析/格式化、侧边栏位置与选中态、历史导航恢复、搜索筛选和详情选择。
- 运行 Web 全量测试、类型检查、生产构建，并检查桌面与移动截图。
